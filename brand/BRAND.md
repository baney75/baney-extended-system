# Brand

**Name:** The Baney Extended System. Short form: BES. The command is `bes`.

**Tagline:** Do. Keep. Know. Let go.

**Line:** Sort by what a thing asks of you.

**Mark:** `mark.svg`. Four rooms, each carrying its paper mark: `>` Do, `<` Keep, `=` Know, `x` Let Go. The Let Go room is dashed because it is held, not sealed.

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#1F2A44` | Text, lines, the mark |
| Paper | `#F6F1E7` | Background |
| Ochre | `#B8862B` | Let Go, and one accent per page |

Ink on Paper has a contrast ratio above 12:1. Ochre is for marks and rules, never for body text.

**Type:** any serif for headings (the system is meant to feel like a well-kept ledger), any clean sans for body. Folder names always appear exactly as on disk: `0 Inbox`, `1 Do`, `2 Keep`, `3 Know`, `4 Let Go`.
