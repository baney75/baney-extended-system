# Notion

Notion pages get a **Room** property with four values: Do, Keep, Know, Let Go.

1. In each database you use (Notes, Tasks, Journal), add a Select property named `Room` with those four options.
2. Add four views, one filtered to each room. Make the Do view sort by date.
3. Class notes default to Know. Journal entries default to Keep. Anything with a due date defaults to Do.

A page can move between rooms as its claim changes: an assignment page is Do until it is submitted, then Keep.
