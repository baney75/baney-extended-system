# Texts, calls and voicemails

Your phone holds the most personal records you have. They belong in **Keep**, by year.

| What | How to get it out | Where it lands |
| --- | --- | --- |
| Voicemails | iPhone: Phone, Voicemail, tap one, Share, Save to Files. Android: most dialers offer Save or Export. | `0 Inbox`, then `2 Keep/<year>/` |
| Call log | Export with a backup tool (iMazing on iPhone, SMS Backup and Restore on Android) as CSV. | `2 Keep/<year>/` |
| Texts | The same tools export a thread as PDF or CSV. Export the threads that matter, not everything. | `2 Keep/<year>/` |
| Voice memos | Share, Save to Files. | `2 Keep/<year>/` |

Name a file after the person when it matters: `2026-11-22 Voicemail (Mom).m4a`. `bes sort` adds the date if the name lacks one, and sends recordings and exported threads to Keep on its own.

Texts that ask something of you (a reply you owe, a date you agreed to) are Do. Answer them on the phone; the system does not try to manage a live conversation.
